## 1. 근거 레벨 정의

**R (외부 연구):**
- R2 = 비슷한 유형의 **행동·음악·청취 중재**에 체계적 근거가 있음. 현재 음원이 연구 프로토콜을 재현했다는 뜻 아님.
- R1 = 제한적·간접적 또는 실험 조건에 크게 의존하는 근거.
- R0 = 현재 제품의 독자적 작용이나 세부 배합에 대해 직접 근거 없음.

**E (시제품 검증):**
- E1 = 파일 형식·채널·길이·해시 등 구현 사실 확인.
- E0 = 목적에 맞는 인체 효과 검증 없음. **현재 전 제품 E0**.

**T (기술 재현):**
- T1 = 파일/코드 근거 확인.
- T2 = 실제 렌더된 전체 신호·장치·사용자 검증; **아직 해당 없음**.

## 4. G-2에 적용할 네 가지 불변 규칙

1. **물리 스펙트럼 검증과 생리적 효능 검증 분리:** 좌우 반송파·비트 차이·피크·LUFS가 맞아도 효능 입증으로 표시하지 않는다.
2. **새 음원·새 조합은 새 제품으로 재검증:** 기존 논문 또는 개별 음원의 효과가 2~3개 혼합 후 합산 유지된다고 가정하지 않는다.
3. **기기 프로필 구분:** 바이노럴은 스테레오 헤드폰 프로필, 다른 콘텐츠는 스피커/헤드폰 가능. 특정 저역 재생에 의존하는 콘텐츠에는 스피커 재현 한계 표시.
4. **원본 생성·라이선스·실재 측정 보존:** 음원마다 코드/커밋/시드/해시, 렌더 조건, 음량·피크, 출처와 이용허락, 근거 URL을 등록한다.

## 5. 출시용 사양 확정 전 필요한 테스트 (PR Gate)

- 각 제품의 `source_commit`, `generator_version`, `seed`, 채널, 길이, RMS·LUFS·true peak, 스펙트럼, 돌발음, 클릭/팝, 루프 연결, 파일 해시를 기록.
- 10종 모두 **원본 합성에서 무손실 WAV를 먼저 생성**하고 마스터링한 뒤 MP3/Opus 파생 파일을 만든다. 현재 7개 파일은 이전 96kbps MP3를 160kbps 재인코딩해 원본 정보가 복원되지 않았다.
- 8Hz·40Hz 대조음원과 원본의 청각적 크기를 비교 조절하고, 인코딩 이후 실제 좌우 분리와 캐리어 보존을 검사.
- 수면/호흡/눈휴식 등 실제 행동중재 요소는 웹 UI 및 시간 스케줄과 일치하는지 통합 테스트.
- 우선은 낮은 음량에서 단독 듣기 → 혼합 듣기 → 출력 장치별 테스트. 물리적 청력 안전을 디지털 피크 값만으로 주장하지 않는다.
- Github 실제 `bf5c253`의 G-1/R-001과 교차 검토한 뒤 **G-2를 확정**한다.

## bf5c253 R-001 대조 후 업데이트 (2026-11-13)

1. R-001의 40Hz 지적은 **부분 수용**. 2019년 생쥐 40Hz 펄스연구는 우리 40Hz 바이노럴의 근거가 될 수 없다. 그러나 2025년 Melnichuk et al. 논문은 사람 대상 40Hz 바이노럴(중심 340Hz 포함)을 실제 시험했다. 80명 모집/분석 대상 64명, 일부 주의력 지표만 개선. `mind_focus`의 320/360Hz는 디지털 주파수만 연구 조건과 일치한다.
2. R-001의 `바이노럴 두 층 동시에 사용하지 말자`는 보수적 배합 정책으로 채택. 물리적 주파수 보존과 효과 합산은 전혀 별개.
3. **근거상 기능명 ≠ 기능이 입증된 파일**. 특히 BODY RELAX의 PMR, EYE REFRESH의 20-20-20, CALM BALANCE의 호흡 수행은 음원만으로 연구개입을 재현하지 못한다. 해당 UI/안내 기능은 아직 추가 개발 과제.
4. 기존 파일 일부는 96 kbps MP3를 다시 인코딩한 것이다. 무손실 마스터로 재합성하기 전 최종 음질·하드웨어 효과 주장을 하지 않는다.
5. 독립 배합 엔진 `src/mix_plan.mjs`는 사양의 **검증 대체물이 아닌 정책 후보**. 조합 메타데이터 계획 175개는 자동 검사했으나, 175개 전체의 실제 오디오 렌더 검사는 하지 않았다.
