# PROJECT CHARTER — 보라다방

상태: 2026-11-13 초안, **사용자 확인 필요**

## 목표

보라다방(https://bora-hp.web.app/)의 가상 공간 및 감성적 소리 경험을 유지하면서, 과학적으로 설명 가능한 음향 처리 기능을 개발한다.

## 병행하는 두 제품 트랙

- **A. 디지털 영양제 10종**: 독립 메뉴 및 단독 청취, 개별 음원·자극 조건의 연구 근거 재검토, 최대 3종 조합(동시/순차 분리), 기기별 출력 모드. 영양성분의 실제 전달이나 치료 효과를 주장하지 않는다.
- **B. 보라다방 스마트 소리 섞기**: 소리가 새로 추가되거나 교체되어도 적용 가능한 공통 분석/배합 엔진. 생활음·자연음·음악·라디오 등 기존 기능 유지. 목적(수면 준비/집중/휴식/자유 감상)에 따라 배합 선택을 보조한다.

## 공통 기반

1. 음원/합성음의 객관적 신호 특성을 측정하고 메타데이터로 관리
2. 원본 주파수/채널/출력 경로 등 기술적 조건을 훼손하지 않도록 제어
3. 원본·개선 버전 A/B 렌더를 재현성 있게 생성
4. 테스트 스크립트/로그/소스 커밋/환경 정보 모두 보관
5. 음향 신호 보존과 건강상 효능 검증을 혼동하지 않음

## 비협상 원칙

- 두 AI 모두 실수할 수 있고, 동의는 증거가 아니다.
- '측정'은 측정 파일과 실행 명령이 있어야 하고, '확인'은 출처 및 조건이 있어야 한다.
- 기능의 임상적 효과를 보증하지 않고, 위험한 음량 설정이나 강한 저주파 출력을 유도하지 않는다.
- 원본 코드·디자인 보존, API 키/비밀정보 및 저작권 보호.
- 배포, 중요한 제품 명세 변경, 의학적 광고 문구는 사용자 승인 필요.

## 사용자 확인할 가정

- 두 트랙은 병렬 개발하되 공통 음향 엔진 규격을 먼저 합의한다.
- 최종 기술 품질은 자동 테스트+청취 평가로 판단한다. 사용자 선호와 의학적 효능은 별개다.
