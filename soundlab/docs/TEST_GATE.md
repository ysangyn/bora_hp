# TEST GATE — 검증 층위 구분

| 검증 층위 | 가능한 주장 | 필요 증빙 | 불가능한 비약 |
|---|---|---|---|
| T0 코드/설정 | 특정 코드 경로가 존재 | 원본 파일+커밋 | 실제 출력 보장 |
| T1 신호 | 특정 주파수/피크/레벨 측정 | 렌더 원본, ffmpeg/분석 코드, 로그 | 청감상 우수함 |
| T2 지각 | 동일 조건 청취 선호, 불편감/마스킹 | 블라인드 비교·기기·음량 조건 | 수면/집중 생리적 효능 |
| T3 기능 | 실제 사용자 과제/수면 일지 변화 | 적절한 통제와 반복/분석 | 질병 치료 또는 일반화된 효과 |
| T4 임상 | 의료적 효능 | 별도 엄격한 임상/규제 검토 | 단순 음원 테스트로 대체 |

## 자동 테스트 최소 요구

- 음원 원본 해시, 채널, 샘플레이트, 길이
- LUFS/샘플 피크/True Peak(버전·명령 기록)
- 무음/클릭·팝/루프 이음매/돌발음 기록
- 최대 동시 배합 케이스에 대한 출력 마스터 신호 렌더
- 난수 합성음은 난수 시드와 설정 기록
- 불완전한 CORS 라디오, 외부 재생 경로는 `NOT_TESTABLE`로 분리
- 바이노럴 신호는 L/R 원본 주파수 보존 검사 및 모노/스피커 시 별도 예외 처리
- 파형을 변경하면 기존 논문 조건에서 벗어나는지 재평가
